Release v1.2.0 verifies every update with a detached signature before applying it, and fixes IPv6 leaks for host targets on IPv4-only tunnels.

### Highlights

- Verify each release archive against a detached signature made with a key that never exists in this repository or in CI, on top of the existing checksum and SLSA provenance checks.
- Fail closed: a missing, malformed or mismatched signature refuses the update, with no flag to skip it.
- Fix IPv6 leaks for host targets on IPv4-only tunnels, where the block chain was flushed on firewall reload and only subnet targets were re-added; host targets are now scoped by client MAC.
- Make the generated routing, split-tunnel and DHCP hotplug scripts run under dash as well as BusyBox ash, instead of exiting at their lock descriptor.
- v1.1.0 does not check signatures, so the first update to v1.2.0 has to be applied by hand; every later update is verified on the device.

Refer to [SUPPLY_CHAIN.md](SUPPLY_CHAIN.md) for verification steps.
