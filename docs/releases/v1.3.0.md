Release v1.3.0 adds an updater health check and makes the two silent auto-update failures impossible to miss.

### Highlights

- Add `updater.sh status`, reporting the installed version, whether a cron entry actually runs the updater, and whether the release public key is present and parses.
- Warn on every run when auto-update is enabled but no cron entry runs the updater, instead of checking nothing in silence.
- Name the fix when no release public key is configured, before downloading a signature that cannot be checked.
- Fail CI when `VPN_UPDATE_PUBKEY` is missing or unparseable in `project.conf`, since no release can repair that on a device.
- Document the one-time key install for devices that predate v1.2.0.

Refer to [SUPPLY_CHAIN.md](SUPPLY_CHAIN.md) for verification and key install steps.
